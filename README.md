# Orbit

Orbit is a circular macOS app launcher. It arranges supported installed apps and Downloads around a translucent ring.

Download the ZIP from Releases, expand it, move Orbit to Applications, and open it. Hover to see a name, then click to launch. You can also use the arrow keys and Return. Escape hides the ring. Use the circle icon in the menu bar to show it again or quit.

The binary targets Apple silicon and macOS 13 or later. It is ad hoc signed and unnotarized, so Gatekeeper may block a downloaded copy. To build locally with the Xcode command line tools, run `./build.sh` and open `build/Orbit.app`.
